## Regeneration

From the repository root, with dependencies installed and assets built:

```powershell
npm run build
npm run start
Invoke-WebRequest -Uri 'http://localhost:3000/api/v1/generate?left=Hello&right=World' -OutFile test/golden/hermit-frame.png -UseBasicParsing
```

Stop the app after the download. Then run `npm test -- --runInBand src/generation/golden.spec.ts`
and confirm it passes with the regenerated bytes.
