## Regeneration

From the repository root, with dependencies installed and assets built:

```powershell
npm run build
npm run start
Invoke-WebRequest -Uri 'http://localhost:3000/api/v1/generate?left=Hello&right=World' -OutFile test/golden/hermit-frame.png
```

Stop the app after the download. Then run `npm test` and confirm
`golden.spec.ts` passes with the regenerated bytes.
