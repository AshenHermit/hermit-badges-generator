# Badge Generator Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-page Next.js UI in `frontend/` that lists templates from the live API, edits their parameters, and shows a preview identical to the generated link.

**Architecture:** `frontend/` is a pnpm/Nx app beside `backend/`. Metadata is fetched in the browser through Next rewrites (backend has no CORS); the preview `<img>` and the copyable link use the same absolute generate URL built from current form values. UI is glass panels over a mouse-parallax background, using shadcn + animate-ui + ReUI color picker.

**Tech Stack:** Next 16 (App Router), React 19, TypeScript strict, Tailwind v4, pnpm 10.12.1, Nx 24, Vitest + Testing Library, shadcn/ui, animate-ui, `@reui/c-color-picker-2`.

**Spec:** `docs/superpowers/specs/2026-11-26-frontend-design.md`

## Global Constraints

- pnpm workspace already declares `backend` and `frontend`; do not edit `pnpm-workspace.yaml`.
- Frontend dev port: `3001`; backend API default: `http://localhost:3000`.
- `NEXT_PUBLIC_API_BASE_URL` default `http://localhost:3000`; production base `https://api.badges.ashen-hermit.space`.
- Browser fetches metadata via relative `/api/v1/...`; Next `rewrites` proxies `/api/:path*` to the API base.
- `height` is always in the generate query: main preview/link use the editable field (default `60`, clamp `1–1000`); template thumbnails use `height=40`.
- Main preview URL and copied link must be the identical string.
- Colors accepted by API: `#RGB`, `#RRGGBB`, `rgb(r, g, b)`; no named colors.
- `format` is `png` or `webp`; non-goal: no backend changes, no deploy changes, no hardcoded template catalog.
- Query keys sorted for deterministic links; unknown/invalid params make the API return 400.

## Review Focus

- API unreachable or 400 on metadata → each affected panel shows an error and Retry, not a blank page. Test: `TemplateList` error/retry test (Task 5) and page integration test (Task 6).
- Generated link must match preview byte-for-byte after edits → test: `useGenerator` equality test (Task 3) and `GeneratorPanel` DOM test (Task 6).
- `height` empty / out of range must still produce a valid API request → test: `buildGenerateSearch` clamp test (Task 2) and generator panel input test (Task 6).
- Empty template list from API must render an empty state, not crash → test: `TemplateList` empty-state test (Task 5).
- Text with spaces/special chars must be URL-encoded and capped at `maxLength` → test: `buildGenerateSearch` encoding test (Task 2).

### Task 2: Types and API/URL helpers

**Files:**

**Interfaces:**

- Produces:

```ts
type ParameterType = "string" | "color" | "integer";
interface TemplateParameter { name: string; placeholder: string; type: ParameterType; required: boolean; default?: string; maxLength?: number; pattern?: string; description?: string }
interface TemplateMetadata { id: string; parameters: TemplateParameter[] }
type ParameterValues = Record<string, string>;

const API_BASE_URL: string;
function listTemplates(signal?: AbortSignal): Promise<string[]>;
function getTemplate(id: string, signal?: AbortSignal): Promise<TemplateMetadata>;
function defaultValues(meta: TemplateMetadata): ParameterValues;
```

`buildGenerateSearch` returns a sorted `URLSearchParams` string. `buildAbsoluteGenerateUrl` returns `${API_BASE_URL}/api/v1/generate?${search}`. `buildThumbnailUrl` uses `format=png`, `height=40`, and sample values (`left: "Hello"`, `right: "World"`, otherwise `default ?? placeholder`) for required params.

  - `buildGenerateSearch` clamps height: `-5` → `height=1`, `5000` → `height=1000`.
  - `buildAbsoluteGenerateUrl("height=60")` equals `http://localhost:3000/api/v1/generate?height=60` when env default applies.
  - `buildThumbnailUrl` contains `height=40`, `format=png`, `left=Hello`, `right=World`.
  - `defaultValues` returns manifest defaults, and for required params without default uses `left: "Hello"`, `right: "World"`, else `placeholder`.
  - `listTemplates`/`getTemplate` fetch `/api/v1/templates` and `/api/v1/templates/<encoded id>` (mock `global.fetch`).
